# Unix-Backup-And-Recovery-System
An automated Unix-based backup and recovery utility that creates timestamped backups, tracks file modifications, maintains backup versions, and enables easy file restoration using C and Bash scripting.
It:
1. Takes a backup of selected files and directories.
2. Stores backups with timestamps.
3. Detects which files have been modified.
4. Maintains multiple versions of backups.
5. Allows users to restore older versions.
6. Automatically performs backups at scheduled intervals.
7. Maintains logs of backup and recovery activities.
